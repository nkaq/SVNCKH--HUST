# Experiment review instructions

Applies to `experiments/`.

Never fabricate or infer missing measurements.

Every research recording should be traceable to:
- recording_id;
- physical Ground Truth;
- fixture/setup version;
- motor ID;
- RPM/load;
- sensor mounting/configuration;
- firmware/software version;
- QC status.

Engineering Validation Data must not be silently promoted to Dataset v0.1.
